A prototype, not ready for classrooms yet. This page checks how a phone's browser reads its motion sensor and microphone (trial T1). Using it with students is the school's decision: classroom phone use needs the district's policy under Utah's phone law (SB 69, 2026). Nothing you measure leaves this device.

1 Motion sensor

Lay this phone flat on a table, screen up. Then press Start.

Lay this phone flat on a table, screen up. Then press Start. It takes 43 seconds: hands off for 30 s, then tap the table 5 times.

2 Microphone optional

Listens for 5 seconds: clap once while it listens. The sound is measured as it arrives and thrown away. Nothing is recorded or saved.

3 Send the results to Gus

Press Copy results and paste them into an email to Gus, with this device's make and model. The CSV file holds every reading, if he asks for it. The site collects nothing: the results go only where you send them.

Log (for troubleshooting)
    No data from seismic stations: this page reads only this device's own motion sensor and microphone. Nothing is sent anywhere. A prototype for trial T1 of the UHSN phone activities.
