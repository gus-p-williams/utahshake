## What this project is

Student-facing web apps and documentation for the **Utah High School Seismic Network
(UHSN)**, run by the Desert Research Institute (DRI). UHSN installs Raspberry Shake
seismometers in small, rural Utah high schools (Phase I: Juab, North Sanpete,
Wasatch Academy, Gunnison Valley, Millard). The apps let technically strong students
see, analyze and do research with seismic data from their own school and the region.

## Key constraints (do not violate)

1. **Raspberry Shake license.** Do not pull data from Raspberry Shake servers
   (data.raspberryshake.org FDSN, CAPS/SeedLink) into our apps or back end, do not
   build a "network-style" page of other Shakes, do not redistribute their real-time
   data. Our own UHSN Shakes, read directly (UDP datacast / SeedLink on the Shake),
   are ours. Link out to StationView/DataView for the wider network.
2. **Student data privacy (Utah R277-487, Student Data Protection Act).** No student
   accounts, names or other PII. Use class codes and anonymous labels. If that ever
   changes, a Utah Student Data Privacy Agreement with each district is required first.
3. **Browser-only for students.** Classroom apps must run in a browser (Chromebooks,
   managed laptops) with no install.
4. **Utah standards.** Each classroom app maps to Utah SEEd standards (PHYS.4.1,
   PHYS.2.1, ESS.2.2, ESS.2.3, ESS.2.6, ESS.4.1, GEOL.3.x) and CS standards
   (9/10.DA.3, 11/12.DA.1). Keep the crosswalk in the docs current.
5. **Attribution.** Every page that shows data cites its source network (e.g. UU,
   doi:10.7914/SN/UU — verify) and USGS ComCat for events.

## Stack and layout (decided)

- Static browser app, plain ES modules, **no build step for the app itself**.
  Third-party libraries (seisplotjs, Leaflet) are vendored as single ESM bundles in
  `docs/app/vendor/`, regenerated by `tools/vendor/` scripts (esbuild).
- Docs: **MkDocs Material**. The app lives inside the docs tree at `docs/app/`,
  so one GitHub Pages site serves both (`/` docs, `/app/` apps).
- Hosting: GitHub Pages via GitHub Actions (`.github/workflows/pages.yml`).
- Data (until UHSN Shakes stream): EarthScope FDSN web services for University of
  Utah (UU) stations near each school, USGS FDSN event service for quakes. All access
  goes through a `DataSource` interface so the UHSN server can be swapped in later.
- Pure logic (distance, location, filters) in small modules with `node --test` tests.
- Later: Python notebooks (ObsPy) for local/research analysis; a scheduled job for
  precomputed products (e.g. hourly noise for the seismic carpet).
