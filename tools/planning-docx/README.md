# Planning doc → Word: equation fix

The Word export of the planning doc (claude.ai Docs → .docx) writes each LaTeX
equation as a plain "Code" paragraph. `fix_equations.py` swaps those five
paragraphs for real Word (OMML) equations generated by pandoc from
`equations.md`, and turns `V_P`, `V_S` and `10^0.3` in body text into proper
subscripts/superscripts. Nothing else in the document is touched.

```bash
pandoc equations.md -o eqs.docx                  # pandoc 3.x (conda: Library/bin/pandoc.exe)
python -I fix_equations.py export.docx eqs.docx fixed.docx
```

If the planning doc gains or loses equations, update `equations.md` (same order
as in the document) and the expected count in the script.
